# Starforge WebIDE Support Policy

This repository provides public community support and documentation for **Starforge WebIDE**.

GitHub Issues may be used to report problems, request enhancements, and identify documentation issues.

---

## Supported Requests

Public GitHub Issues are appropriate for:

- Reproducible software defects
- Unexpected WebIDE behavior
- User-interface problems
- Browser compatibility issues
- SysML v2 editing problems
- Visualization problems
- Documentation errors
- Documentation improvement requests
- Feature requests
- General product usability feedback

---

## Before Opening an Issue

Before submitting a new issue:

1. Check the repository Wiki.
2. Review the FAQ and troubleshooting information.
3. Search existing GitHub Issues.
4. Determine whether an existing issue already describes the problem.

If an existing issue matches your problem, please add relevant information there instead of creating a duplicate.

---

## Information to Include

For technical problems, please provide as much of the following information as possible:

- Starforge WebIDE version
- Browser name and version
- Operating system
- Description of the problem
- Steps to reproduce
- Expected behavior
- Actual behavior
- Relevant error messages
- Relevant logs
- Screenshots where useful
- Minimal synthetic SysML v2 example

A reproducible example significantly improves our ability to investigate a problem.

---

## Sensitive and Proprietary Information

This repository is public.

**Do not submit confidential, proprietary, controlled, or sensitive information.**

In particular, do not upload:

- Customer models
- Proprietary engineering models
- Customer requirements
- Customer architecture information
- Confidential project information
- Export-controlled information
- ITAR-controlled information
- Classified information
- Personally identifiable information
- Passwords
- Authentication credentials
- API tokens
- Private URLs containing credentials
- Internal network information that should not be publicly disclosed

If a model is required to demonstrate an issue, create a minimal synthetic model containing only the elements required to reproduce the problem.

By submitting information to this repository, you acknowledge that the information will be publicly visible.

---

## Security Problems

Security vulnerabilities must not be submitted through public GitHub Issues.

Please follow the process described in [SECURITY.md](SECURITY.md).

---

## Commercial or Contractual Support

This GitHub repository is not a replacement for commercial, contractual, or customer-specific support arrangements.

Customers with an existing support agreement should use the support channel identified in their applicable agreement.

GitHub Issues do not establish:

- A guaranteed response time
- A service-level agreement
- A commitment to fix a reported issue
- A commitment to implement a requested feature
- A specific delivery date

---

## Feature Requests

We welcome feature requests.

Please describe:

1. The problem or workflow being addressed.
2. The desired capability.
3. The expected user experience.
4. Why the capability would be useful.
5. An example use case, where possible.

Feature requests may be reviewed as input to product planning.

Submission or acceptance of a feature request does not constitute a commitment to implement the requested capability.

---

## Issue Resolution

Issues may be closed for reasons including:

- Fixed
- Duplicate
- Unable to reproduce
- Insufficient information
- Expected behavior
- Unsupported environment
- Documentation updated
- Feature request recorded
- Not currently planned
- Outside the scope of Starforge WebIDE

Where practical, we will explain the reason when closing an issue.

---

## Internal Development Tracking

Confirmed issues may be transferred or copied into internal development systems.

Internal development repositories, planning systems, schedules, or implementation details may not be publicly accessible.

Public GitHub Issues may be updated when relevant information becomes available.

---

## Response Expectations

We will make reasonable efforts to review submitted issues.

However, this public repository is provided on a best-effort basis and does not guarantee:

- Response times
- Resolution times
- Continued availability
- Compatibility with every environment
- Implementation of requested features

Commercial support obligations, where applicable, are governed exclusively by the relevant customer agreement.
